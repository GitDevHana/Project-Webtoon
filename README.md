# Project Webtoon — 제작 파이프라인과 독자 사이트

소설을 모바일 세로 스크롤 웹툰으로 각색하고, 편집 가능한 식자를 조립해 독자 사이트에 게시하는 개인 프로젝트입니다. 이 저장소는 **공개 가능한 구현과 재현 예제**를 모았습니다. 원작 원고, 회차별 전체 콘티, 실제 생성 프롬프트, 원화, 운영 계정·데이터는 포함하지 않습니다.

## 실제 서비스

**[컷온 — 서비스 바로가기](https://projectwt-webtoon-library.sjvigox12.chatgpt.site/)**

로그인 없이 작품 목록과 웹툰을 열람할 수 있습니다. 휴대폰에서는 세로 스크롤 원고와 화면 너비에 따른 표시를 확인할 수 있습니다. ChatGPT 로그인 후에는 작품·회차 업로드와 본인 콘텐츠 관리 기능을 사용할 수 있습니다.

사이트에서 결과물을 확인하고, 아래 공개 코드에서 제작·편집·보안 구현을 살펴볼 수 있습니다.

## 무엇을 만들었나

- **제작 파이프라인:** 원작 범위와 인과관계를 정한 뒤 장면의 기능·시선·컷 형태를 설계하고, 원화와 편집 가능한 문자 레이어를 독립적으로 관리합니다. `renderer/`는 명시적인 컷 배치 데이터에서 오프라인 HTML과 편집 문서를 조립합니다.
- **웹툰 편집기:** `editor/`는 기존 공개 코드입니다. 같은 문자·풍선 데이터를 화면과 저장본에서 사용해 배치, 수정, 실행 취소, 재정렬을 지원합니다.
- **독자 사이트 보안:** `site-security/`에는 운영 소스에서 선별한 파일 공개 판정, 업로드 용량의 원자적 예약, 계정별 요청 제한, 최소 감사 기록과 실제 API 핸들러를 담았습니다. 개인 설정과 공개 원고는 제외했습니다.

## 공개한 자료

| 경로 | 내용 |
| --- | --- |
| `editor/` | 편집기 소스와 테스트 |
| `renderer/` | 배치 계약, HTML 조립기, 풍선 렌더링 |
| `site-security/lib/` | 사이트의 실제 보안 함수와 요청 핸들러 발췌 |
| `site-security/db/` | 관련 스키마와 마이그레이션 |
| `site-security/test-public.mjs` | 공개 코드로 실행하는 독립 검증 예제 |
| `docs/` | 파일 구조, 익명화한 프롬프트 예시, 보안 사례와 검증 범위 |

`site-security/lib/community.mjs`는 실제 사이트의 핸들러 발췌입니다. 전체 사이트 빌드에 필요한 인증·카탈로그·UI·운영 데이터는 이 저장소에 없습니다. 독립적으로 실행할 수 있는 검증은 `site-security/test-public.mjs`에 한정됩니다.

`renderer/` 역시 원화·실제 회차 데이터·글꼴이 빠진 구조 및 구현 공개본입니다. 전체 회차 생성 명령을 이 저장소만으로 실행할 수 있다고 주장하지 않습니다.

## 공개 범위와 설명 책임

가상의 짧은 프롬프트 예시는 [docs/PROMPT_SAMPLE.md](docs/PROMPT_SAMPLE.md)에 있습니다. 실제 작품의 숨겨진 설정이나 전체 프롬프트 템플릿을 재현하지 않습니다. 보안 구현은 [docs/SECURITY_CASE.md](docs/SECURITY_CASE.md)에 문제·코드·검증·한계를 연결해 설명했습니다. 테스트 통과가 외부 침투 테스트나 서비스 전체의 무취약성을 뜻하지는 않습니다.

AI 도구를 제작과 구현 보조에 사용했습니다. 설계 판단, 코드 수정, 원작 대조, 테스트 결과와 한계를 직접 검토해 기록했습니다.
