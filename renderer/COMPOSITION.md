# 편집 가능한 장면 내 식자 — 13화 이후 제작 계약

특정 회차·원고의 배치나 글꼴을 복제하는 지침이 아니다. 현재 장면의 인물, 명암, 공간, 읽는 순서에서 구도를 설계한다.

- 그림·풍선·글자는 별도 편집 레이어지만 하나의 화면으로 작화 전에 설계한다. 글자는 사람이 확정한 문자열만 출력한다.
- **그려진 효과음 예외:** 위 편집 가능한 문자 계약은 대사·독백·서술을 대상으로 한다. 효과음/동작어/연출음은 확정 문구를 메타데이터에 보존한 독립 투명 이미지 또는 획 벡터 자산으로 조립할 수 있다. 원화에 합쳐 굽거나 일반 폰트 문자로 자동 되돌리지 않는다. `sfx`라는 문자열 항목만 넣으면 현재 조립기가 캘리그라피로 만들어 준다는 뜻은 아니다. 해당 자산 경로·변환·겹침·클리핑을 실제 지원하는 경로로 연결하고 검증해야 한다. 현재 `compose_episode.py`의 일반 `lettering` 경로는 여전히 평문이므로 그려진 효과음 구현 완료로 간주하지 않는다.
- 대사는 화자 주변의 실제 빈 공간, 독백은 현재 시선/관찰 대상과 이어지는 배경에 놓는다. 어깨·배경·옷 위의 겹침은 허용한다. 핵심 얼굴·손·행동이 읽히지 않을 만큼 가릴 때만 조정한다.
- 컷 위/아래 여백은 전환·침묵·리빌 등의 이유가 있을 때 쓴다. 모든 글을 위로 쌓거나 그림을 글자 높이만큼 내리지 않는다. 반대로 모든 글을 그림 안에 강제로 넣지도 않는다.
- `lettering.layout.rect`는 원화의 `art_rect` 안에 한정하지 않는다. 장면 캔버스 안에서 컷 바깥 여백이나 경계를 걸치는 위치도 설계할 수 있다. 컷의 사선/비정형 마스크가 풍선·문자를 함께 자르지 않게 하며, 자연스러운 읽기와 과도한 가림 방지를 우선한다. 공통 원칙은 PROMPT.md의 통합 구도 절을 따른다.
- 실제 대사 길이를 넣은 러프에서 인물 자리, 식자 사각형, 꼬리 도착점, 시선 흐름을 정한다. 문자 수로 폭을 몇 단계로 고르거나 컷 번호의 홀짝/나머지로 배치를 정하지 않는다.
- 이미지 생성 요청에는 해당 컷의 인물/카메라/행동과 식자 예약 영역의 좌표·배경 성격을 전달한다. '상하15~20% 비우기'를 공통 복제하지 않는다. 생성 이미지에는 문자·숫자·풍선·상자 윤곽을 그리지 않는다. 예약 영역은 배경의 일부이며 흰 사각 구멍이 아니다.
- 그림이 예약 구도와 어긋나면 해당 컷 배치/그림만 조정한다. 일괄 공백 추가나 생성된 인물 크롭으로 덮지 않는다.

## 단일 데이터

storyboard 최상위에 `lettering_contract: 2`, `typography: {family, font_file, weight}`를 둔다. 한글 폰트는 프로젝트 안의 배포 가능한 파일을 선택해 편집 JSON/HTML에 함께 내장한다. 기존 래스터 원고의 폰트 이름을 추정해서 확정하지 않는다. 현재 폰트 미선정이며 제작 전에 확인한다.

각 컷의 `composition`:
- `height`, `art_rect: [x,y,w,h]`, `gap` — 1080 폭 장면 좌표. 그림 원비율은 확인해 유지한다.
- `reason`, `reading_flow` — 그 배치가 현재 장면에 맞는 이유와 읽는 순서.
- 핵심 표정/손/행동은 기존 콘티의 초점·공간 데이터에 기록하고 겹침 판단에 참조한다.

기존 `lettering` 항목에 확정 `text`, `text_kind`, 화자와 `layout`을 연결한다:
- `rect: [x,y,w,h]`, `font_size`, `align` 필수.
- `line_height`, `padding: [top,right,bottom,left]`, `font_weight`, `color`, `stroke_width`는 필요한 항목만 지정.
- 발화/생각은 장면 좌표의 `tail_target: [x,y]`와 `tail_side: top|bottom|left|right` 필수.
- 새 부드러운 말풍선은 최상위 `balloon_style: "soft-oval-short-v1"`로 선택한다. `tail_target`은 화자 쪽 **방향 기준**이며 입까지 꼬리를 늘이는 명령이 아니다. 이 스타일의 공통 렌더러는 둥근 몸체와 한 윤곽으로 이어지는 짧은 곡선 꼬리, 몸체 가까운 생각 점을 그린다. 원고 좌표·글자·풍선 사각형·겹침은 바꾸지 않는다. 선택 필드 `tail.maxLength`는1080좌표 기준 기본72, 허용36~84다. 기존 회차/비본편은 스타일을 명시하지 않으면 기존 모양을 유지한다.
- `lines`는 선택적 명시 줄바꿈이며 원문 글자를 바꾸지 않는다.
- 자유 효과음도 실제 텍스트 레이어로 두고 동작 옆에 좌표를 정한다.
- 각 컷 `art_asset`은 해당 회차 디렉터리 기준 그림 경로.

`approved_text`가 있으면 `text`와 완전히 같아야 한다. 원문 선택의 의미 검수는 콘티 단계에서 수행하며 이 일치 검사로 대신하지 않는다.

## 제작 진입

```text
python renderer/compose_episode.py episodes/EP13/EP13_storyboard.json --check
python renderer/compose_episode.py episodes/EP13/EP13_storyboard.json
```

13화 자료가 아직 없으므로 위는 다음 제작 시 사용할 명령 예시다. 좌표나 폰트가 없으면 오류를 내고 멈춘다. 이전 회차의 assemble.py를 복사해 자동 적층하지 않는다. `--draft`는 시스템 폰트로 배치만 확인하는 초안이며 완성·배포용이 아니다.

조립기는 입력한 좌표를 그대로 편집 JSON/HTML로 만들고 풍선과 글자는 `editor/core.js`의 공통 동적 렌더러로 그린다. 글자 수정 후 저장된 SVG 그림으로 고정하거나 기존 자동 풍선으로 바뀌지 않는다. 그림을 다시 생성하지 않고 글자·풍선 위치/크기/꼬리/줄바꿈을 수정할 수 있다.

## 기존 검수에 합쳐 확인

작화 전 기존 러프 검토에 대화·독백·둘이 섞인 연결 장면을 포함한다. 유형 할당량이나 별도 전수검수 문서를 늘리지 않는다. 현재 장면의 시선·빈 공간을 따라 배치됐는지 본다. 필드 존재만으로 미관 통과를 기록하지 않는다.

최종 대표 컷에서 문구/글자 크기/풍선 크기와 위치를 바꾼 뒤 실행취소·저장·HTML 재불러오기를 확인한다. 장문이 넘치면 해당 상자/줄바꿈만 조정하며 원문 자동 축약·글꼴 임의 대체·그림 자동 이동은 하지 않는다. 오타 검사는 확정 문자열 대조와 실제 한글 표시를 모두 확인한다.

## 컷 순서 편집

왼쪽 컷 목록에서 항목을 위/아래 경계로 드래그하면 그림·풍선·글자가 포함된 구간 전체가 함께 이동한다. 선택한 항목에서 Alt+↑/↓로도 이동할 수 있다. 실행취소/다시실행·저장·수정 요청의 panelOrder/orderChanged에 반영되며 컷 ID와 원작 연결은 유지한다. 순서 변경만으로 새 그림을 만들지 않는다.
