# 공개용 프롬프트 예시

아래는 **가상의 등장인물과 사건으로 새로 작성한 짧은 예시**입니다. 실제 회차 프롬프트, 원작 문장, 캐릭터 설정, 생성 모델별 세부 파라미터는 포함하지 않습니다. 목적은 결과를 통제하는 항목과 검수 방식을 보여주는 것입니다.

```text
입력: 비가 그친 뒤 두 사람이 같은 우산을 접는다.
한 사람은 대답을 피하고, 다른 사람은 그 침묵을 눈치챈다.

장면 기능: 대답을 미루는 행동을 독자가 먼저 알아차리게 한다.
구도: 젖은 우산 끝을 전경에, 두 사람의 손과 눈길을 한 장면에 둔다.
연기: 질문한 사람의 표정은 기대에서 의아함으로 변한다.
연속성: 우산은 두 사람 사이에서만 이동하고, 접힌 상태를 다음 장면까지 유지한다.
식자: 질문과 짧은 속생각을 같은 장면에 둘 수 있다. 손과 눈을 가리지 않는다.
금지: 원작에 없는 고백, 화해, 초능력, 새로운 인물의 개입.
검수: 누가 우산을 들었는지, 시선이 어디로 이동하는지, 다음 장면과 손의 위치가 맞는지 확인한다.
```

실제 제작에서는 장면마다 원작 범위와 정보 공개 시점, 인물·장소의 고정 속성, 화면에서 꼭 읽혀야 할 행동, 프레임·스크롤 리듬, 식자 위치, 실패 조건을 데이터로 관리합니다. 공개 예시만으로 비공개 작품의 전체 제작 계약을 복원할 수는 없습니다.
