# 공개용 구조와 실제 제작 흐름

```text
Project-Webtoon/
├─ editor/                 편집 가능한 문자·풍선·컷 순서와 검증
├─ renderer/               명시적 배치 데이터 → 편집 문서·오프라인 HTML
├─ site-security/
│  ├─ lib/                 사이트 보안 함수와 API 핸들러 발췌
│  ├─ db/                  관련 데이터 모델과 마이그레이션
│  └─ test-public.mjs      비공개 계정·원고 없이 실행하는 검증
└─ docs/                   공개 범위·프롬프트 예시·보안 사례
```

실제 작업 공간에는 원작과 참조 이미지, 회차별 콘티·원화·편집 데이터, QA 결과가 별도로 있습니다. 이 자료는 저작물과 운영 정보를 포함하므로 공개 저장소에 복사하지 않았습니다. 공개 저장소의 예시는 구조와 판단 과정을 설명하기 위한 작은 독립 자료입니다.

제작은 `원작 범위 확인 → 비트와 정보 공개 시점 → 장면별 콘티·시선 지도 → 원화 → 식자·효과음 → HTML 조립 → 모바일 스크롤·편집 왕복 검수` 순서입니다. 대사 한 문장을 한 컷으로 기계적으로 나누지 않고, 각 컷에 행동·표정·해설·긴장 또는 전환 기능을 부여합니다. `renderer/COMPOSITION.md`는 실제 조립 데이터의 요구사항을 설명합니다.

보안 쪽은 `업로드 → 비공개 소유자 열람 → 작품/회차에 연결된 경우 공개 → 참조 제거 시 공개 취소`라는 파일 수명주기를 다룹니다. `site-security/lib/security.mjs`는 공개 여부와 용량·요청 제한을, `community.mjs`는 API 경로에서 이 검사를 호출하는 방식을 보여줍니다.
